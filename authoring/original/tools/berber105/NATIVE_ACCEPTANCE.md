# Berber 1.0.5 native acceptance

1.0.5 contains exactly the 1.0.4 game archive. Offline preservation, authoring,
cook and storage checks do not establish native acceptance. The user imports
and tests the release; no game launch is part of this consolidation.

1. Import Berber-1.0.5.zip in the normal Garrison client. Select Malians, the
   Berber tuning pack and Berber game mode in a fresh match.
2. Check native AI opening gathering, construction, unit production, age
   advancement, research, Tribal Tent/alliance unlocks and combat across the
   difficulties you use. Include Nomad and water where applicable.
3. Check all-age buildings/units, player colors, repaired UVs, Tuareg shields,
   unit speech without stock overlap, and the music controls/age transitions.
4. Check save/load and multiplayer separately if those are intended uses.
5. If needed, reimport the untouched Berber-1.0.4.zip rollback. Its game archive
   is identical, so it does not supply a different AI/gameplay implementation.
