# Berbers — Garrison 0.1.0

1. Close Age of Empires IV completely.
2. Import `Berbers-Garrison-0.1.0.zip` into Garrison client 0.1.9 or newer.
3. Enable Berbers in Civilizations; disable the old replacement Berber package.
4. Launch through Garrison. Choose **Berbers**, **Standard**, **Tuning Pack: None**.
5. Use a human Dark Age start with a stock opponent for the qualified pilot route.

The owner accepted trial.3 loading and working. This release preserves its
existing gameplay and uses the Villager's original artwork for civilization
flags. Check dropdown, player list, Codex and loading presentation after launch.

Starting army: one capital Town Center, six Villagers and one Scout. Resources
before spending/gathering: 200 Food, 200 Wood, 100 Gold, 50 Stone. Tribal Tents,
alliances, influence, units, voices, music and lifecycle resources remain.
Some stock visual components are intentional in the original art set.

Broader age-up/training/ability coverage, AI, later-age starts, Nomad, save/load,
repeated matches, replays, multiplayer and performance need separate native tests.
Preserve warnings.log and Garrison logs before relaunching to diagnose problems.
Rollback: close AoE4 and reimport the retained trial.3 ZIP, or disable this package
and use the original replacement mod.
